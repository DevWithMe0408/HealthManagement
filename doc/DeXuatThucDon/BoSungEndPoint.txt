File 2: RecommendationApiService.java — tính target khi build response
Tìm method toMealResponse() (hoặc tương đương — nơi build từ entity sang MealSuggestionResponse). Hiện đã có mealKcalTarget, chỉ cần thêm 3 phép tính từ goal_configs:
java// Tính macro target dựa trên mealKcalTarget và tỉ lệ macro của goal
// goalConfig có 3 field: proteinRatio, fatRatio, carbRatio (lưu trong DB, vd 0.30 / 0.25 / 0.45)

BigDecimal mealKcal = meal.getMealKcalTarget();

// Protein: kcal × ratio / 4 (4 kcal per gram protein)
BigDecimal proteinTarget = mealKcal
    .multiply(goalConfig.getProteinRatio())
    .divide(BigDecimal.valueOf(4), 1, RoundingMode.HALF_UP);

// Fat: kcal × ratio / 9 (9 kcal per gram fat)
BigDecimal fatTarget = mealKcal
    .multiply(goalConfig.getFatRatio())
    .divide(BigDecimal.valueOf(9), 1, RoundingMode.HALF_UP);

// Carb: kcal × ratio / 4 (4 kcal per gram carb)
BigDecimal carbTarget = mealKcal
    .multiply(goalConfig.getCarbRatio())
    .divide(BigDecimal.valueOf(4), 1, RoundingMode.HALF_UP);

return MealSuggestionResponse.builder()
    .mealType(meal.getMealType())
    .mealKcalTarget(mealKcal)
    .proteinTarget(proteinTarget)  // mới
    .fatTarget(fatTarget)           // mới
    .carbTarget(carbTarget)         // mới
    .topCombination(...)
    .slotAlternatives(...)
    .build();
Lưu ý: kiểm tra lại tên field thật trong GoalConfig entity của bạn. Memory tôi có ghi nhận goal_configs là 1 trong 6 bảng config ổn định — nếu field tên khác (vd proteinPercent thay vì proteinRatio, hoặc giá trị lưu 30 thay vì 0.30) thì điều chỉnh code cho đúng. Đọc file GoalConfig.java trước khi sửa.

Test nhanh sau khi code:
Gọi POST /api/recommendation/full-day với body mẫu, check response có đủ 3 field mới. Ví dụ với goal "GIAM" (giảm cân), bữa Trưa 840 kcal, ratio 0.30/0.25/0.45:

proteinTarget: 840 × 0.30 / 4 = 63.0g
fatTarget: 840 × 0.25 / 9 = 23.3g
carbTarget: 840 × 0.45 / 4 = 94.5g

Nếu số ra khớp, BE xong. FE chỉ cần xoá block hardcode meal.target * 0.2 / 4 và đọc trực tiếp meal.proteinTarget / meal.fatTarget / meal.carbTarget từ response.
